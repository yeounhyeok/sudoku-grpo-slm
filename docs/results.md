# 평가 결과 (test_id 64문제)

## 프로토콜
- 같은 64문제(`random.Random(0).sample`, 난이도 구성: hard 27 / medium 24 / easy 8 / expert 5), 문제당 k=8 샘플.
- 디코딩 T=0.6, top-p 0.95, presence penalty 1.5, 생성 상한 32k. 24k 열은 24,576토큰 이내에 끝난 정답만 정답으로 센 값.
- 채점은 학습 보상과 같은 규칙(유효 격자 + 정답 일치).
- 표준오차: medium 24k 기준 ±7%p 안팎. 같은 64문제로 여러 체크포인트를 비교했으므로 선택 편향 가능.

해석(실측과 추정 구분):
